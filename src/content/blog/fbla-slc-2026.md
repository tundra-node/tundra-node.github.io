I'm competing in the Cybersecurity event at FBLA's State Leadership Conference this April. It's a 100 question multiple choice test with a 50 minute time limit, covering pretty much everything. Network security, cryptography, malware, compliance frameworks, you name it.

To study I built a [little web app](/fbla-cybersecurity-2026/) with flashcards, timed mock quizzes, a cheat sheet, and a progress tracker. It's built with Vite, React, and Tailwind if you're curious.
